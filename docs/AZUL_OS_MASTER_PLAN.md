# AZUL OS - MASTER PLAN

Versión: 1.0
Estado: En desarrollo
Proyecto: Estación Azul

---

# Visión del Proyecto

AZUL OS será una plataforma integral para administrar todos los procesos de Estación Azul desde un solo sistema.

El objetivo es contar con un ERP moderno, rápido, intuitivo y escalable, desarrollado en Flutter Desktop, con integración futura a SUNAT y otros servicios.
